Windows says “Windows protected your PC”?

That is the SmartScreen warning for new software with few downloads yet. Click “More info”, then “Run anyway”. You can compare the file's SHA-256 with the list above to make sure it was not modified.

Verify the download

Open PowerShell in the folder that holds the file, run the command below and compare the result with the version's SHA256SUMS.txt:

Get-FileHash .\LightViewer-*-x86_64.exe
