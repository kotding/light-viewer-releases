Frequently asked questions

Can't find your answer? Send us your question through the bug report / feedback page.

Is LightViewer free?

Yes. LightViewer is free for personal use, with no ads, no session time limit and no account needed.

Is LightViewer safe?

Every session is end-to-end encrypted between the two computers, so neither the server nor the relay can see your screen, keystrokes or files. Nobody can get in without the ID and password, or without you accepting. Only share your ID and password with people you trust.

Why does Windows warn me when I open the installer?

Windows SmartScreen warns about new software that does not have many downloads yet. Click “More info”, then “Run anyway”. You can check the SHA-256 on the Download page to make sure the file is the original.

Does it need to be installed on both computers?

Yes. Both the controlling and the controlled computer need LightViewer. The person being helped can run it without installing for a one-off session.

Does it work over mobile data?

Yes. On most networks the computers connect directly. Some mobile or corporate networks block direct connections; then traffic goes through a relay (still encrypted) at a limited speed.

Is there a version for Android, Ubuntu or macOS?

Windows 10/11, Ubuntu 22.04+ (.deb) and Android are available. On Ubuntu, install with sudo apt install ./LightViewer-…-x86_64.deb. On Android, download the .apk (ARM64 for most phones) and allow installing apps from that source. macOS will be considered later.

How do I reach my home PC when nobody is there?

Install LightViewer on it and set a permanent password in Settings → Security. See “Unattended access” in the Guide.

When does the temporary password on the home screen change?

It stays the same for the whole run, even after someone connects. It changes only when you refresh it, when the computer restarts, or after many wrong attempts in a row. Set a permanent password for regular access.

Does the app update itself?

Yes. LightViewer checks for new versions. Updates are digitally signed and the app installs only builds with a valid signature.

What data does LightViewer store about me?

The server keeps only the device ID, its public key and last IP address so the two computers can find each other. No screen, files or keystrokes are stored. Details in the Privacy policy.

Why do I get “Failed to connect to relay server”?

The computers could not connect directly and the relay was not reachable. Check both computers' Internet and retry in a few minutes. If it keeps happening, let us know.

How is LightViewer different from RustDesk?

LightViewer is built on RustDesk (AGPL-3.0 license), with its own interface, servers and update channel.
