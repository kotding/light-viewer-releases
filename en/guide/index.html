User guide

From installation to remote control and file transfer – each part takes just a few steps.

On this page

  • 2. Control another computer
  • 3. Unattended access
  • 4. Transfer files

1. Install LightViewer

  1. Go to the Download page and get LightViewer-…-x86_64.exe.
  2. Open the file. If Windows shows “Windows protected your PC”, click “More info”, then “Run anyway”.
  3. Choose “Install” so LightViewer starts with Windows (needed for unattended access), or use it right away without installing.
  4. The home screen shows your computer's ID and password. The temporary password stays the same until you refresh it or restart the computer.
  • Ubuntu / Debian: download the .deb and run sudo apt install ./LightViewer-…-x86_64.deb.
  • Android: download the .apk (ARM64 for most phones), open it and allow installing apps from that source.

Both computers need LightViewer: the one controlling and the one being controlled.

2. Control another computer

  1. Ask the other person for the ID and password shown in their LightViewer.
  2. Type the ID into the “Partner” box on your computer and click “Connect”.
  3. Enter the password when asked. Or leave it empty and wait for the other person to click “Accept”.
  4. The remote window opens. Use the top toolbar to switch displays, send Ctrl+Alt+Del, chat or disconnect.

3. Unattended access

Use this to reach a home or office computer when nobody is there to read you the password.

  1. On the computer to reach, install LightViewer (not the run-without-install mode).
  2. Open Settings → Security → “Unlock security settings”.
  3. Under Password, choose a permanent password and set a strong one.
  4. Note the computer's ID. From now on the ID and the permanent password are all you need.

Use a long password you don't use anywhere else. Anyone with this ID and password can get in.

4. Transfer files

  1. On the home screen, click the folder icon under “Connect” to switch to file transfer.
  2. Enter the other computer's ID and connect as usual.
  3. A two-pane window opens: your computer on the left, the remote one on the right. Select files and click the arrow to send.

During a remote session you can also copy a file on one computer and paste it on the other.

5. Stay in control when being helped

  • When someone connects, a small window in the corner shows who is connected.
  • You can turn off keyboard/mouse, audio, clipboard or file transfer right there.
  • Click “Disconnect” at any time to end the session.
  • Defaults for every session are in Settings → Security → Permissions.

6. Updates and uninstalling

  • LightViewer checks for new versions and asks before updating. Only builds with a valid digital signature are installed.
  • To uninstall, open Windows Settings → Apps, find LightViewer and choose Uninstall.

7. Troubleshooting

  • “Failed to connect to relay server” / cannot connect: check both computers' Internet, then retry in a few minutes. Mobile data or strict corporate networks may need the relay, which is slower.
  • The remote computer is reported offline: open LightViewer on it and wait for the status line at the bottom to show “Ready”.
  • Wrong password: the temporary password changes when refreshed – ask for the one currently shown.
  • Choppy picture: lower the image quality in the session toolbar, or close bandwidth-heavy apps.
