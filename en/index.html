Everything you need for remote control

As light as a chat app, powerful enough for everyday work.

Low latency

Direct P2P connections and hardware video encoding (H.264/H.265) keep the picture smooth and input instant.

End-to-end encryption

File transfer

Unattended access

You control permissions

Allow keyboard, mouse, audio, clipboard, file transfer… or end the session with one click.

Safe automatic updates

Multi-monitor and audio

Connect in 3 steps

  1. 1

    Install on both computers

    Download LightViewer and open it. Each computer gets its own ID and password.

    Enter the remote computer's ID

    Click Connect

    Type the password and you see their screen. That's it!

A clean, simple interface

Everything important is right on the home screen.

Private by design

LightViewer is built so the server knows as little about you as possible.

The picture goes straight between computers

On most networks the screen and files travel directly peer to peer, never through a middle server.

Relay only when needed, still encrypted

When a network blocks direct connections (mobile data, corporate networks) traffic goes through a relay, still end-to-end encrypted – the relay cannot read it.

No account, no tracking

Frequently asked questions

Is LightViewer free?

Yes. LightViewer is free for personal use, with no ads, no session time limit and no account needed.

Is LightViewer safe?

Every session is end-to-end encrypted between the two computers, so neither the server nor the relay can see your screen, keystrokes or files. Nobody can get in without the ID and password, or without you accepting. Only share your ID and password with people you trust.

Why does Windows warn me when I open the installer?

Windows SmartScreen warns about new software that does not have many downloads yet. Click “More info”, then “Run anyway”. You can check the SHA-256 on the Download page to make sure the file is the original.

Does it need to be installed on both computers?

Yes. Both the controlling and the controlled computer need LightViewer. The person being helped can run it without installing for a one-off session.

Does it work over mobile data?

Yes. On most networks the computers connect directly. Some mobile or corporate networks block direct connections; then traffic goes through a relay (still encrypted) at a limited speed.
