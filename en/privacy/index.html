Privacy policy

This policy explains what data LightViewer (the app, the connection servers and this website) handles and why. Our rule: handle only what is needed for two computers to connect.

Last updated: 2026-11-04

What we never see

  • Screen images, audio, keystrokes, clipboard and files transferred in a session.
  • These are end-to-end encrypted between the two computers; even when they pass through the relay, the relay cannot decrypt them.
  • Your access password is never sent to the server in readable form.

Data the connection server handles

So that two computers can find each other, the connection (ID) server keeps for each device:

  • The device ID and a random identifier created by the app.
  • The device's public key, used to set up the encrypted connection.
  • The latest public IP address and port, network (NAT) type and online status.

Relay

When the computers cannot connect directly, session data goes through a relay server. The relay only forwards encrypted packets; it neither stores nor can read them. The relay is bandwidth-limited to keep the service free.

System logs

The servers keep technical logs (registration time, ID, IP address) to run the service and prevent abuse. Logs are kept temporarily, rotated automatically and never used for advertising.

Update checks

The app periodically downloads a version file from GitHub (github.com) to learn about new releases. The request carries no device ID; GitHub may record the IP address under GitHub's own policy.

Website

This website is static: no cookies, no analytics, no ads. It is hosted on GitHub Pages and reads the release list from GitHub; GitHub may record the IP address under GitHub's own policy.

Sharing

We do not sell or share your data with third parties, unless required by law.

Your rights

  • You can stop using and uninstall the app at any time; a device that no longer connects sends no further data.
  • You can ask for your device ID to be removed from the server through the bug report / feedback page.

Changes

When this policy changes we update this page and the “Last updated” date above.
